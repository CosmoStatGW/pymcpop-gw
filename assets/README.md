# Project logo

Two orbiting compact objects and a gravitational-wave curve.

- [SVG](pymcpop-gw-logo.svg): editable, scalable vector; used in the main README.
- [PNG](pymcpop-gw-logo.png): 512 × 512 pixels, with a transparent background.

Both use the same artwork and work on light and dark backgrounds. The SVG can
be displayed at 40–48 pixels beside the project name.
